# Roadmap

`create-skills` is intentionally small today. Future work focuses on resilience, onboarding, and quality.

## Active areas

- Resilient CLI execution (`run --timeout --retry`)
- Skill search and filtering (`list --filter --json`)
- Onboarding commands (`init`, `config`)
- Skill validation (`validate`)
